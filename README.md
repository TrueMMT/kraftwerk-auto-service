# KRAFTWERK Auto Service — Portfolio Demo

Modern responsive demo website for a fictional German auto repair shop.

## Features
- Responsive single-page design
- DE / SK / CZ / EN language switcher
- Services, process, price cards, contact section
- Booking modal with local demo persistence
- Login/register demo using localStorage only
- Scroll reveal animations, animated counters, responsive navigation
- Custom SVG logo and car artwork — no paid assets
- Zero build tools and zero dependencies

## Run locally
Open `index.html` in a browser, or serve the folder with any static server.

## Deploy for free
Works on GitHub Pages, Cloudflare Pages, Netlify, Vercel, etc.

## Important
This is a portfolio/demo project. Company name, address, phone, testimonials, statistics and prices are fictional. Login/register is not production authentication and should be replaced with a real backend for a client project.
